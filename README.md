# Analyse comparative du risque entre actions et cryptomonnaies

Projet personnel de finance quantitative et gestion des risques réalisé en Python.

## Objectifs
- Comparer le profil de risque des actions et des cryptomonnaies
- Étudier les distributions de rendements
- Implémenter plusieurs mesures de risque :
  - Volatilité
  - Value-at-Risk (VaR)
  - Expected Shortfall (ES)
- Étudier les corrélations entre actifs
- Analyser l’impact des cryptomonnaies dans un portefeuille diversifié

## Outils utilisés
- Python
- pandas
- numpy
- matplotlib
- scipy
- yfinance

## Actifs étudiés
- Apple (AAPL)
- Microsoft (MSFT)
- SPY (S&P500 ETF)
- Bitcoin (BTC-USD)
- Ethereum (ETH-USD)
